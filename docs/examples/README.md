- **[custom_theme_conf.md](custom_theme_conf.md)** - Using `[tool.fairdm.docs]` for theme selection
- **[fairdm_portal_conf.md](fairdm_portal_conf.md)** - Full metadata extraction for a FairDM portal
- **[cli_usage.md](cli_usage.md)** - Working through the command-line tool
